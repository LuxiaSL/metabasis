# Entry points for the import-closure check (check_import_closure.py).
#
# One module per line: the dotted name, then `#` and the reason the module is an
# entry point although no script and no test imports it. A listed module seeds
# the traversal the way a script under metabasis/scripts does, so the modules it
# imports are reached through it. A line without a reason is refused; a listed
# name that is no module here fails the check; a listed module the import graph
# reaches anyway is reported as redundant, so a stale entry is seen and removed.
#
# What earns an entry is an entry point the import graph cannot see: a module
# run on its own with `python -m`, or one a third-party runtime loads by a name
# held in a string. "Nothing imports it yet" is not a reason; that module is an
# orphan, and the fix is a test that imports it, or its removal.
#
# An entry is a claim that its reason is true NOW. If the reason has expired, the
# entry goes, whatever it used to protect.

metabasis.capacity                # run as `python -m metabasis.capacity`: the per-card VRAM estimate, with a --selftest
metabasis.jobs_v21                # run as `python -m metabasis.jobs_v21`: renders the job-script template family and proves it, with a --selftest
metabasis.lineage_discriminators  # run as `python -m metabasis.lineage_discriminators`: its module docstring gives the command
metabasis.l4_blind.cli            # run as `python -m metabasis.l4_blind.cli <command>`: the blind-judging tool's only front door
